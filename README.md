# Coin Bag for Home Assistant

Home Assistant add-on that lets your HA host act as the "Nintendo Switch" for Pokémon GO's postcard exchange over Bluetooth, hands-free.

Add this repository in Settings → Add-ons → Add-on store → ⋮ → Repositories, then install **Coin Bag**.
See `coinbag/README.md` for usage. Protocol work by [na-ji/pokemon-go-coin-bag](https://github.com/na-ji/pokemon-go-coin-bag); its constants are fetched at image build time and not stored here.
